Roads Between the Courses

Prompt framework in Claude 101 is the 4D Description competency applied to a specific tool
Common challenges all trace back to the same 4D gaps — generic responses are Description failures, blind trust is Discernment failure
Projects = persistent Description. Skills = codified Description. Memory/Styles = user-level Description. Same principle at three scales.
Connectors are Delegation multipliers that raise the Diligence bar. More access to your data means more responsibility for how it's used.
Research mode is Delegation at its fullest — but the more you delegate, the more your Discernment skills matter.
The tools change. The framework stays. AI Fluency is tool-agnostic. Claude 101 proved it — every feature maps back to the same four competencies.
